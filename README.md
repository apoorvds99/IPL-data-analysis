# IPL Data Analysis (Exploratory Data Analysis)

This project performs Exploratory Data Analysis (EDA) on Indian Premier League (IPL) match data to uncover meaningful insights related to teams, toss decisions, venues, and match outcomes using Python.

Project Overview:

The notebook explores 2022 IPL match data and answers questions such as:

Which teams have won the most matches?

Does winning the toss influence match results?

What are the common toss decisions?

Which venues host the most matches?

What are the biggest winning margins?

Which players and teams have delivered record performances?

The goal of this project is to demonstrate data cleaning, analysis, visualization, and interpretation skills.
